# 7 Days To Die Archipelago

**Archipelago Implementation for 7 Days To Die**

## Installation

### Install the APWorld

Grab the Archipelago.rar and APworld from the releases page.


You can install the APWorld in either of two ways:

* **Automatic:** Double-click the `.apworld` file and allow Archipelago to install it.
* **Manual:** Place the `.apworld` file in your `Archipelago\custom_worlds` folder.

### Install the 7 Days To Die mod

Extract `Archipelago.rar` into your 7 Days To Die `Mods` folder.

Your installation should look like:

```text
7 Days To Die
└── Mods
    ├── 0_TFP_Harmony
    └── Archipelago
```

### Disable Easy Anti-Cheat

Make sure **Easy Anti-Cheat is disabled** when launching 7 Days To Die through Steam.

The Archipelago client requires the game to be running without Easy Anti-Cheat.

## Connecting to an Archipelago World

1. Launch the **7 Days To Die** client through the Archipelago Launcher.
2. Enter your Archipelago room connection information:

   * Room address
   * Slot name
   * Password, if required
3. Connect to the room.
4. Load into a **fresh save**.
5. Play normally and receive your Archipelago progression through the client.
